# NICOLE SRL - Negozio di Abbigliamento

## 1. Project Overview

- **Project name**: NICOLE SRL
- **Type**: Single-page fashion boutique website
- **Core functionality**: Showcase a clothing store in Terracina with navigation, hero section, services, and contact info
- **Target users**: Local customers in Terracina looking for fashion clothing

## 2. UI/UX Specification

### Layout Structure

- **Single page application** with smooth scroll navigation
- **Sections**: Header/Nav, Hero, Chi Siamo, Servizi, Collezioni, Contatti, Footer
- **Responsive breakpoints**:
  - Mobile: < 768px
  - Tablet: 768px - 1024px
  - Desktop: > 1024px

### Visual Design

**Color Palette**:
- Primary: `#1a1a1a` (nero elegante)
- Secondary: `#f5f0eb` (crema/bianco antico)
- Accent: `#c9a87c` (oro spazzolato)
- Text: `#333333`
- Background: `#ffffff`

**Typography**:
- Headings: "Playfair Display", serif (elegant, fashion-forward)
- Body: "Raleway", sans-serif (clean, readable)
- Logo: "Playfair Display" bold

**Spacing**:
- Section padding: 80px vertical
- Container max-width: 1200px
- Standard gap: 24px

**Visual Effects**:
- Subtle fade-in animations on scroll
- Hover effects on buttons and cards
- Smooth scroll behavior
- Parallax-like hero background

### Components

1. **Navigation Bar**
   - Fixed top, white background with subtle shadow
   - Logo left, menu right
   - Mobile: hamburger menu

2. **Hero Section**
   - Full viewport height
   - Background image with overlay
   - Headline + CTA button

3. **Chi Siamo (About)**
   - Image + text layout
   - Company history and values

4. **Servizi**
   - 3-4 service cards in grid
   - Icons + descriptions

5. **Collezioni**
   - Grid of collection categories
   - Image cards with hover effects

6. **Contatti**
   - Contact form
   - Store info (address, phone, hours)
   - Map placeholder

7. **Footer**
   - Social media icons (Instagram, Facebook)
   - Copyright
